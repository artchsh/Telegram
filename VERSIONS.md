# SkyGram — версии

Модифицированная сборка Telegram для Android. Здесь ведутся **наши** версии —
чтобы не путать их с версией Telegram, на которой основана сборка.

| Версия | Основа (Telegram) | Что вошло |
|--------|-------------------|-----------|
| **v1.0** | 12.10.3 (7089) | Первый релиз — см. ниже |

## v1.0 — 24.09.2026
Основа: **Telegram Android 12.10.3 (7089)**

Интерфейс:
- убрана нижняя навигационная панель (Чаты / Контакты / Звонки / Профиль);
- вместо «трёх точек» — круглая аватарка пользователя;
- по тапу: другой аккаунт (мгновенное переключение), добавить аккаунт, создать группу,
  избранное, настройки;
- в Настройки добавлены строки «Контакты» и «Мой профиль».

Брендинг:
- название **SkyGram** (в лаунчере и в интерфейсе);
- иконка 🛸 (U+1F6F8) на чёрном squircle + вектор для тематических иконок;
- в тулбаре и на экране приветствия — самолётик + «SkyGram».

Техническое:
- release-сборка (R8/сжатие/оптимизация ресурсов выключены), arm64-v8a;
- собственный `api_id`/`api_hash` (нет `API_ID_PUBLISHED_FLOOD`), ключи в `local.properties`;
- **фикс тёмной темы**: `core.autocrlf` ломал переводы строк в `assets/*.attheme`,
  из-за чего цвета парсились в 0 и текст был невидим → добавлен `.gitattributes`,
  ассеты приведены к LF, кэш встроенных тем сбрасывается при обновлении;
- кэш встроенных тем (`Theme.java`) инвалидируется при обновлении приложения.
